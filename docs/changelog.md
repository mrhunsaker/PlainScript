# Changelog

Authoritative release notes and change history are maintained in git tags, commits, and project
release workflows.

## Recommended Sources

- GitHub Releases: <https://github.com/mrhunsaker/PlainScript/releases>
- Commit log: <https://github.com/mrhunsaker/PlainScript/commits/main>

## Tag Format

PlainScript release tags follow:

```text
vYYYY.MM.DD
```

Examples:

- `v2026.05.06`
- `v2026.12.31`

Use:

```bash
npm run release:tag
```

or

```bash
npm run release:tag -- v2026.05.06
```
